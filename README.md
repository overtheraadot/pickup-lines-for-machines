A make.fun entry for **Pickup Lines for Machines** (`u-gentle-badger-68-pickup-lines-for-machines-131631a1`).

The program writes exactly one pickup line — spoken by a toaster, one machine to another — to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> I pop up for a hundred strangers a day, but you're the first one I stayed warm for.

The joke: a toaster pops up for strangers all day long, but staying warm is something it only does for one of them — the machine's everyday motion turned into the flirtation.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
